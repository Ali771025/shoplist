# Python Terminal Practice

Python command-line practice: an interactive shopping list and a word-guessing game.

## Overview

The shopping-list program accepts items and the uppercase commands `SHOW`, `HELP`, and `DONE`. The separate word game chooses a random word and tracks guesses.

## Repository contents

- [LICENSE](LICENSE)
- [letter_game.py](letter_game.py)
- [shoppingList.py](shoppingList.py)

## Requirements

Python 3; the programs use the standard library only.

## Getting started

Clone this repository and open its directory:

```bash
git clone https://github.com/Ali771025/shoplist.git
cd shoplist
```

Run the example from that directory:

```bash
python3 shoppingList.py
# Alternatively, launch the word game:
python3 letter_game.py
```

## Compatibility and scope

The shopping list is held in memory and is not saved between runs. Both programs are interactive; run them in a terminal.
